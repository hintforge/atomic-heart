Spoiler-controlled, NORA-or-Charles-flavored reference for P-3's Atomic Heart playthrough. AI agent sessions opened here read this file for orientation, then look up topics in the subfolders below.

## Hard rules
- **Spoiler-free unless tier raised.** No story beats, no enemy reveals, no encounter telegraphs. (See `warning_tiers.md`.)
- **PC (mouse + keyboard).** Translate any controller references before quoting. See `controls.md` for KB&M remap notes.
- **Hint ladder for puzzles & combination locks.** Smallest nudge first; escalate on request.
- **Don't invent solutions.** If no source has it, say so and link the closest source.
- **Every claim cites a source** in the structured form (see `../../hintforge/templates/claim_format.md`).
- **Russian/Soviet terminology flexibility.** Transliteration variants are common (Kollektiv/Collectiv, Nora/NORA, etc.); accept any spelling, prefer canonical in-game English text.
