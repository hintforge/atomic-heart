# Nav — Chelomey City (Prologue)

**zone-id:** chelomey_city_prologue
**status:** research-integrated
**research_run:** P2 (Compass/Deep Research 2026-05-08)

## Entry / Exit

- **Entry:** Game start (canal-boat cutscene).
- **Exit (E01):** Flying-car (Turbina) takeoff cutscene → sechenov_office_prologue. Story-gate; point of no return for prologue achievements.

**NORA booth:** None — prologue zone.

## Sequential Gates

1. **Boat Disembark** (cutscene) — arrive on the canal pier. The payphone ("How Can I Help You?" achievement) is on a side wall near the fountain — interact before moving to the plaza.
   > _Missable achievement: interact with the payphone near the fountain before reaching Sechenov Tower. Cannot return after E02. [C:3]_
2. **Polymer-Day Plaza** (trigger) — open-air square with hammer-and-sickle ceiling and statues; first scripted NPC interactions.
3. **Future Lab Demo Room** (trigger) — robot demo behind glass.
4. **Sechenov Tower Lobby** (door) — atrium leading to the elevator.
5. **Sechenov Office Elevator** (story-gate) — riding this elevator is the point of no return for the payphone achievement.
6. **Twins Key Pickup** (cutscene) — first scan target. [C:4]
7. **Turbina Takeoff** (cutscene) — interact with the parked flying car in the plaza; triggers the crash. [C:4]

## Common Confusions

- Payphone is on a side wall near the fountain — easy to miss when following objective markers.
- Triggering the flying-car interaction locks the achievement permanently.
